# UiPath - UI Automations

A collection of UiPath automation workflows demonstrating basic to intermediate UI and file automation techniques, including Notepad file interactions and automated weather data handling using Excel.

## 📁 Repository Structure

```text
├── Main.xaml                         # Main entry workflow
├── Notepad File saving automation.xaml # Workflow for automating Notepad text entry and saving
├── weather excel file automation.xaml # Workflow for automating weather data extraction/logging to Excel
├── NP_practice.txt                   # Sample text file used for Notepad automation tasks
├── Weather_data.xlsx                 # Excel workbook for reading/storing weather data
├── project.json                      # UiPath project configuration file
├── project.uiproj                    # UiPath project definition file
└── entry-points.json                 # Execution entry points configuration
